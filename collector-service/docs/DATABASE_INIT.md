# Инициализация базы данных

## Для новых развертываний

Если вы разворачиваете проект с нуля, используйте один из следующих способов:

### Способ 1: Использование начальной миграции (рекомендуется)

Начальная миграция `55aabbccddee_initial_migration.py` содержит все таблицы с актуальной структурой:

```bash
# Применить только начальную миграцию
alembic upgrade 55aabbccddee
```

### Способ 2: Использование скрипта инициализации

```bash
# Запустить скрипт инициализации
python scripts/init_db.py
```

### Способ 3: Применить все миграции

```bash
# Применить все миграции последовательно
alembic upgrade head
```

## Для существующих баз данных

Если база данных уже существует и нужно применить только новые миграции:

```bash
# Проверить текущее состояние
alembic current

# Применить все новые миграции
alembic upgrade head
```

## Структура миграций

- **55aabbccddee** - Начальная миграция (создает все таблицы с актуальной структурой)
- Последующие миграции - применяются только для обновления существующих баз

## Важно

- Начальная миграция включает все изменения: `plan_visibility`, гибкие `participants`, `event_priorities` и т.д.
- Для новых развертываний достаточно применить только начальную миграцию
- Для существующих баз нужно применять все миграции последовательно
